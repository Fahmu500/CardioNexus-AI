# Contributing to CardioNexus AI

Thank you for your interest in contributing to CardioNexus AI! This project aims to save lives through open-source cardiac artificial intelligence, and every contribution matters.

## How You Can Help

### Clinicians & Medical Researchers
- Review clinical logic and biomarker thresholds
- Suggest evidence-based improvements to risk models
- Validate novel risk factor hypotheses against published literature
- Help design clinical validation protocols

### AI/ML Engineers
- Add unit tests for model architectures
- Improve model training pipelines
- Optimize inference performance
- Add new model architectures with clinical relevance

### Software Engineers
- Improve code documentation
- Add integration tests
- Enhance the clinical dashboard
- Improve API endpoints

### Everyone
- Report bugs via GitHub Issues
- Suggest features
- Improve documentation
- Star the repo and share it

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Run syntax checks: `python -m py_compile cardionexus_core.py`
5. Commit: `git commit -m "Add: description of your change"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## Code Style

- Follow PEP 8 for Python code
- Add docstrings to all classes and public methods
- Include type hints for function signatures
- Comment complex clinical logic with references to medical literature

## Important Notes

- This is a research platform, not a certified medical device
- Never use this for actual clinical decisions without proper validation
- All novel risk factor hypotheses need prospective clinical validation
- Patient data must never be committed to the repository
